# Random Blocks

Fabric-мод: блоки мира становятся случайными. Воздух, вода и лава не трогаются.

Меняются только полные кубы. Песок и гравий не ставятся — сыпались бы. Цветы, трава, двери, факелы, плиты и листва удаляются **без дропа**.

Раскладка считается от сида мира: в каждом мире своя, на том же сиде — та же.

## Измерения

Пулы блоков **разделены**:

- **Верхний мир** — все стабильные полные кубы, кроме адских и эндовских
- **Ад** — адские блоки (незерак, базальт, чёрный камень, незер-руды…)
- **Энд** — эндовские блоки (энд-стоун, пурпур…)

## Масштаб замены

По умолчанию `1×1×1` (каждый блок сам по себе).

| Команда | Эффект |
|---------|--------|
| `/randomblocks scale 1` | кубики 1×1×1 |
| `/randomblocks scale 2` | кубики 2×2×2 |
| `/randomblocks scale 4` | кубики 4×4×4 |
| `/randomblocks scale 8` | кубики 8×8×8 |
| `/randomblocks scale 16` | кубики 16×16×16 |
| `/randomblocks scale chunk` | **весь чанк** = один случайный блок |

Масштаб сохраняется в мире. Уже обработанные чанки сами не пересчитываются — снова `/randomblocks` или новые чанки.

## Требования

- Minecraft 1.21.1
- Fabric Loader
- Fabric API

## Команды

- `/randomblocks` — все загруженные чанки; новые меняются, когда до них доходите
- `/randomblocks around 8` — только вокруг себя
- `/randomblocks border 32` — ванильная граница мира, радиус в чанках
- `/randomblocks pregen 32` — заранее прогрузить и прорандомить квадрат вокруг спавна
- `/randomblocks scale …` — размер кубиков / весь чанк
- `/randomblocks auto false` — выключить авторандом новых чанков

`border 500` можно, но это около миллиона чанков. Преген такого размера идёт часами в фоне.

## Установка

`build/libs/random-blocks-1.1.0.jar` (не `-sources`).

Prism: инстанс 1.21.1 + Fabric → Mods → Fabric API и этот `.jar`. Лучше новый мир.

## Сборка

Нужен JDK 21.

```bat
gradlew.bat build
```
